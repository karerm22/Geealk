# جييلك  GEEILAK

موقع عربي لخدمة طلب المشاوير والتواصل مع فريق جييلك.

## محتويات المشروع

- `index.html` — الصفحة الرئيسية للموقع، وتشمل التصميم والأنماط والبرمجة اللازمة لتشغيل الواجهة.
- `README.md` — تعريف بالمشروع وطريقة تشغيله ونشره.
- `package.json` — بيانات تعريف المشروع وأوامر مساعدة بسيطة.
- `.gitignore` — ملفات لا يلزم رفعها إلى Git.
- `.nojekyll` — يساعد GitHub Pages على نشر الملفات كما هي.

## التشغيل محليًا

الموقع ثابت (Static Website) ولا يحتاج إلى تثبيت مكتبات أو قاعدة بيانات لتشغيل الواجهة.

يمكن فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح: <http://localhost:8000>

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع جميع ملفات هذا المجلد إلى المجلد الرئيسي للمستودع.
3. افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages نفسها.

## ملاحظات

- الصفحة باللغة العربية واتجاه العرض من اليمين إلى اليسار.
- الخطوط تُحمّل من Google Fonts؛ لذلك يلزم اتصال بالإنترنت لظهورها بالشكل المحدد.
- راجع بيانات التواصل والأسعار والمناطق داخل `index.html` قبل النشر للتأكد من أنها البيانات النهائية المعتمدة.
- هذا المشروع واجهة موقع ثابتة؛ أي وظائف تتطلب حفظ بيانات أو لوحة تحكم أو إدارة حجوزات فعلية تحتاج إلى ربط بخلفية برمجية (Backend) وخدمة تخزين مناسبة.
